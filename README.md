# CSP-S 2026

本仓库整理 CSP-J/S 2026 第二轮提高组公开的选手代码。目前收录浙江省（`ZJ`）。

`ZJ/选手代码/` 按考号、题目名保留原来的目录与文件；`ZJ/answers.zip` 和 `ZJ/提高组选手答案概要信息.docx` 为浙江省公示的原始文件副本。

压缩包中的目录名和文件均保持原样。Git 不记录空目录；如需恢复包括空目录在内的完整原貌，请解压 `ZJ/answers.zip`。本仓库不包含官方测试数据或官方评测成绩。

数据来源：浙江省 NOI 系列竞赛报名系统发布的《CSP-J/S 2026第二轮认证（浙江省）普及组和提高组代码密码公开》。
